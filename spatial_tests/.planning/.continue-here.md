# Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| latent==structure illusion | MultiDCP `global_features` looks like an "expression latent" but within a fixed basal context its only per-drug-varying part is the 128-d drug block (cell_hidden + dose constant, std 1.8e-8, empirically validated). The expression arm is therefore MultiDCP's drug encoder, not an expression representation. | advisory | Report the near-zero +expression lift AS the finding (two encoders carry the same info). For a genuinely expression-distinct latent, tap the post-expert/gene-output stage instead. |
| argparse import collision | `cache_region_de.py` runs a strict module-level argparse; any custom CLI flag (`--encoder`, `--checkpoint`) in a script that imports it (even lazily) gets parsed by it and errors. | advisory | `latent_three_way.py` resets `sys.argv=[sys.argv[0]]` after its own parse, before the lazy import; `gate4a` uses env `GATE4A_CKPT`. Reuse these patterns. |
