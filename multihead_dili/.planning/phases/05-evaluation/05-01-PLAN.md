## Goal

Write `src/stage2/evaluate_dili.py` implementing:
1. DeLong paired AUROC test (all-three var7 vs embed-only var1)
2. 10K bootstrap CIs for AUROC per cell
3. ECE calibration per cell
4. Aggregate all 21 cells and emit results

## Implementation Tasks

### 1. DeLong's paired AUROC test

Use the structural components method (Hanley-McNeil / DeLong 1988).
- Collect all (true_label, predicted_proba) pairs for var7 and var1, paired on same drugs
- Compute the covariance matrix of the two AUROCs
- Compute z-statistic = (AUROC_var7 - AUROC_var1) / sqrt(Var(AUROC_var7) + Var(AUROC_var1) - 2*Cov(AUROC_var7, AUROC_var1))
- Two-sided p-value from z

### 2. 10K Bootstrap CIs

For each cell (variant × head × split):
- Pool all prediction files for that cell across folds and seeds
- Bootstrap 10K times (sample with replacement over drugs)
- Compute AUROC each resample
- 95% CI = [2.5th, 97.5th] percentile

### 3. ECE Calibration

- 10-bin ECE for each cell (same pooled predictions)
- Report mean ± std ECE

### 4. Output

- Dictionary per cell with: AUROC_mean, AUROC_std, CI_lower, CI_upper, AUPRC_mean, ECE_mean, n_drugs, n_runs

## Success Criteria

- DeLong p-value for var7 vs var1 on scaffold split is computed
