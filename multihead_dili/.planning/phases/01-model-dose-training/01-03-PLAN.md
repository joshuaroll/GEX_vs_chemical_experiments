  <action>
  ```bash
  conda run -n dili_v04_env python -c "
  import torch, sys
  ckpt = torch.load('results/checkpoints/chkpt_dose.pt', map_location='cpu')
  if ckpt['halt_gate_1_pass']:
      print('HALT GATE 1: PASS — MODEL_DOSE beats predict-mean baseline.')
      print('Phase 1 complete. Safe to proceed to Phase 2 (MODEL_GEX).')
      sys.exit(0)
  else:
      print('HALT GATE 1: FAIL')
      print(f'Dev RMSE={ckpt[\"dev_rmse\"]:.4f} >= Baseline RMSE={ckpt[\"baseline_rmse\"]:.4f}')
      sys.exit(1)
  "
  ```

  **Status:** NEEDS REVIEW

  ## Trigger

  MODEL_DOSE dev RMSE ≥ predict-mean baseline RMSE.

  ## Values

  | Metric | Value |
  |--------|-------|
  | Dev RMSE (MODEL_DOSE) | {dev_rmse:.4f} |
  | Baseline RMSE (std of dev labels) | {baseline_rmse:.4f} |

  The trained MODEL_DOSE does not beat the trivial predict-mean baseline on the dev set.
