## Tasks

### Task 1: Write `src/stage2/classifiers.py`

Implement three DILI classifier heads as PyTorch nn.Module:

- `LinearHead(input_dim)` → input_dim → 1 (no hidden layers, raw logit output)
- `MLP1Head(input_dim)` → input_dim → 128 → 1 (ReLU, Dropout(0.3))
- `MLP2Head(input_dim)` → input_dim → 256 → 64 → 1 (ReLU, BatchNorm1d, Dropout(0.3))

Factory function `build_head(head_name, input_dim)` → returns the appropriate head.

### Task 2: Write `src/stage2/train_dili_classifier.py`

Grid driver with:

1. Feature slicing: define `VARIANT_COLS` dict mapping variant → list of column name prefixes
2. Data loading: load `dili_features.parquet` once; slice feature matrix per variant in-memory
3. Split generation:
   - scaffold: load `dili_split.json`; 5-fold CV within train+val, test fixed
   - random: `StratifiedKFold(n_splits=5, shuffle=True, random_state=42+fold_idx)`
4. Training loop per (variant, head, split, fold, seed):
   - Set all random seeds deterministically: `torch.manual_seed(seed)`, `np.random.seed(seed)`, `random.seed(seed)`
   - Build DataLoader (batch_size=64, shuffle=True for train)
   - Adam(lr=1e-3, weight_decay=1e-4), BCEWithLogitsLoss with pos_weight for class imbalance
   - Train up to 100 epochs; early stopping patience=10 on val BCE loss
   - At end: predict on test fold; write prediction parquet
5. Output per run:
   - `data/processed/predictions/var{v}_head{h}_split{s}_fold{f}_seed{r}.parquet`
   - Columns: pert_id, drug_name, true_label, predicted_proba, predicted_label, fold, seed, variant, head_depth, split_type
6. WandB: log auroc, auprc, mcc, balanced_acc per run to group `multihead_dili`
7. After grid: aggregate to `data/processed/P4_runs.parquet`
