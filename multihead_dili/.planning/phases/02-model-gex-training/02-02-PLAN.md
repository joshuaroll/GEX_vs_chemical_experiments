`--max_epoch 100`). Log all metrics to WandB (`joshroll/MultiDCP_multihead_dili`, group

Launch training from the `multihead_dili/` working directory. Use `conda run -n dili_v04_env`
or activate the env first. The command is:

```bash
conda run -n dili_v04_env python src/train/train_model_gex.py \
  --safe_parquet data/processed/lincs_train_safe.parquet \
  --gpu <CHOSEN_GPU_FROM_T1> \
  --max_epoch 100 \
  --batch_size 64 \
  --seed 343 \
  --dropout 0.3 \
  --num_workers 4 \
  --saved_model_name results/checkpoints/chkpt_gex.pt \
  --wandb_project joshroll/MultiDCP_multihead_dili \
  --wandb_group model_gex \
  --top_k_de 80 \
  2>&1 | tee results/tables/P2_training.log
```
